# Reviews

Add real Google Play reviews (with the reviewer's permission or as shown publicly on Play) as
`<app-slug>.json`, for example `life-in-the-uk.json`:

```json
[
  { "name": "Sara K.", "text": "Passed first time thanks to the mock tests!", "rating": 5 }
]
```

They appear in the Reviews section of that app's page on the next deploy.
